## 🧾 Descrição do Projeto

Este repositório apresenta uma **análise exploratória de dados (EDA)** desenvolvida durante a **Imersão Dados com Python II**, um programa intensivo de aprendizado prático em análise de dados promovido pela Alura.

O projeto tem como objetivo explorar um dataset real utilizando Python, aplicando técnicas de limpeza, análise estatística e visualização de dados para identificar padrões, relações e insights relevantes. O resultado final é a publicação no Streamlit de um dashboard com as principais informações.

Ao longo das etapas, foram utilizadas bibliotecas amplamente adotadas no mercado de dados para manipulação, análise e visualização de informações.

---

## 🎯 Objetivos

* Praticar análise exploratória de dados com Python
* Aplicar técnicas de limpeza e preparação de dados
* Explorar relações entre variáveis por meio de estatísticas e visualizações
* Desenvolver raciocínio analítico e storytelling com dados
* Construir um projeto prático para portfólio em ciência de dados

## 📊 Etapas da Análise

### 1. Importação e Exploração Inicial

* Carregamento do dataset
* Inspeção das primeiras linhas
* Identificação de tipos de dados
* Verificação de valores nulos

---

### 2. Limpeza e Preparação de Dados

* Tratamento de valores ausentes
* Conversão de tipos de dados
* Criação de variáveis derivadas
* Padronização de colunas

---

### 3. Análise Exploratória de Dados (EDA)

* Distribuição de variáveis
* Estatísticas descritivas
* Análise de correlação
* Identificação de padrões e tendências

---

### 4. Visualização de Dados

Foram utilizados gráficos para facilitar a interpretação dos dados, como:

* Histogramas
* Boxplots
* Gráficos de dispersão
* Mapas de calor (heatmaps)

Essas visualizações ajudam a identificar relações entre variáveis e possíveis insights para tomada de decisão.
